## 先把运行过程连起来 { #os-map }

程序运行时，需要 CPU 时间、共享资源、内存与持久存储。沿着下面六个问题读，把“何时执行”“等待谁”和“数据在哪里”放回同一个过程；各模型的编号与单位要分别理解。

<div class="lab-catalog" markdown="1">

- <span class="lab-tag">01 / CPU 时间</span>

    **什么时候轮到我？第一次运行与最终完成差在哪里？**

    在同一组进程上切换 FCFS 与 RR，观察时间轴、就绪队列和三个时间指标。

    [打开调度时间轴 →](02-进程与线程/进程线程与调度.md#scheduling-lab)

- <span class="lab-tag">02 / 地址映射</span>

    **程序里的地址，怎样找到物理内存？**

    拆出页号与偏移，沿 TLB、页表追到页框，区分未命中、缺页和非法访问。

    [打开地址转换 →](03-内存管理/内存管理基础.md#paging-lab)

- <span class="lab-tag">03 / 内存容量</span>

    **页面不在内存，是否一定要换出别的页？**

    同步推进 FIFO 与 LRU，分别数清命中、缺页和实际换出。

    [打开页面置换 →](03-内存管理/虚拟内存与页面置换.md#replacement-lab)

- <span class="lab-tag">04 / 共享资源</span>

    **已经阻塞，就一定发生了死锁吗？**

    追踪两把锁的持有者与等待边，比较交错执行、统一加锁顺序和串行执行。

    [打开锁等待推演 →](02-进程与线程/同步互斥与死锁.md#locks-lab)

- <span class="lab-tag">05 / 文件内容</span>

    **文件里相邻的字节，为什么可能落在不相邻的数据块？**

    经过直接指针与一级间接项，区分正文长度、索引容量与分配空间。

    [打开文件块索引 →](04-文件管理/文件系统.md#fileindex-lab)

- <span class="lab-tag">06 / 设备请求</span>

    **服务顺序一样，磁头移动总量为什么还不同？**

    比较四种调度，检查端点折返、等距请求和零距离服务。

    [打开磁盘调度 →](05-输入输出管理/缓冲与磁盘.md#disk-lab)

</div>

## 怎么使用这个专栏

每章先看**本章导览**，再看对应知识点，最后进入**王道习题与错题**。习题会按教材版次、章节和题号定位，并链接回相关知识点；做错或暂时没有独立解决的题，会保留复做记录，不直接标记为掌握。

```mermaid
flowchart LR
    A[知识点] --> B[王道习题]
    B --> C[错题复做]
    C -->|仍有疑问| A
```

跨章节的问题放进[易混概念](综合复盘/易混概念.md)和[计算题与常见陷阱](综合复盘/计算题与常见陷阱.md)。
