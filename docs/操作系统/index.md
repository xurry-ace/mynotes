## 怎么使用这个专栏

每章先看**本章导览**，再看对应知识点，最后进入**王道习题与错题**。习题会按教材版次、章节和题号定位，并链接回相关知识点；做错或暂时没有独立解决的题，会保留复做记录，不直接标记为掌握。

```mermaid
flowchart LR
    A[知识点] --> B[王道习题]
    B --> C[错题复做]
    C -->|仍有疑问| A
```

跨章节的问题放进[易混概念](综合复盘/易混概念.md)和[计算题与常见陷阱](综合复盘/计算题与常见陷阱.md)。
