# 操作系统：知识点与王道习题

这个专栏用于整理操作系统知识点，以及做王道计算机考研操作系统习题时形成的理解、解题过程和错题复盘。内容会随着学习与复做逐步补充。

## 按章节学习

1. [操作系统概述](01-操作系统概述/index.md)：先建立操作系统的整体认识。
2. [进程与线程](02-进程与线程/index.md)：把调度、同步与死锁串起来。
3. [内存管理](03-内存管理/index.md)：整理地址转换、分配和虚拟内存。
4. [文件管理](04-文件管理/index.md)：梳理文件、目录与文件系统。
5. [输入输出管理](05-输入输出管理/index.md)：梳理设备、缓冲和磁盘相关内容。

## 怎么使用这个专栏

每章先看**本章导览**，再看对应知识点，最后进入**王道习题与错题**。习题会按教材版次、章节和题号定位，并链接回相关知识点；做错或暂时没有独立解决的题，会保留复做记录，不直接标记为掌握。

```mermaid
flowchart LR
    A[知识点] --> B[王道习题]
    B --> C[错题复做]
    C -->|仍有疑问| A
```

跨章节的问题放进[易混概念](综合复盘/易混概念.md)和[计算题与常见陷阱](综合复盘/计算题与常见陷阱.md)。
