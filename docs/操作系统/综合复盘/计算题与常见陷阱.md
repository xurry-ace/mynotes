## 五类计算，各自先检查什么？

| 计算对象 | 落笔前先确认 | 结果检查 | 逐步核对 |
| --- | --- | --- | --- |
| CPU 调度 | 到达、服务、抢占、时间片、同一时刻入队规则 | CPU 总执行量等于服务量；响应与周转分别从到达起算 | [调度时间轴](../02-进程与线程/进程线程与调度.md#scheduling-lab) |
| 分页地址转换 | 编址单位、页大小、页号范围、页表和驻留状态 | 余数小于页大小；转换前后偏移不变 | [地址转换](../03-内存管理/内存管理基础.md#paging-lab) |
| 页面置换 | 输入是地址还是页号、初始页框、容量和淘汰规则 | 命中加缺页等于引用总数；区分首次装入与换出 | [FIFO / LRU](../03-内存管理/虚拟内存与页面置换.md#replacement-lab) |
| 文件块索引 | 块大小、直接指针数、间接项大小、文件长度和查询偏移 | 逻辑块从 0 开始；间接项减去直接区覆盖量；正文与元数据分开计空间 | [文件偏移到数据块](../04-文件管理/文件系统.md#fileindex-lab) |
| 磁盘调度 | 磁道范围、初始位置、方向、等距规则及停止条件 | 每段绝对位移相加；端点折返计距离，不额外计请求 | [四种路径对照](../05-输入输出管理/缓冲与磁盘.md#disk-lab) |

### 用默认数据核对边界

- RR 的 `q=2` 是每轮最多运行 2 个时间单位，不能把进程总服务量也改成 2。
- `1300 B` 除以页大小 `1024 B` 得到页号 1、偏移 276 B；物理地址还要用**页框号**重新计算。
- 初始页框全空时，第一次引用页面 1 是缺页，但有空框可装入，所以置换次数仍为 0。
- 文件偏移 `4096 B` 已进入逻辑块 4，一级间接项是 `I[0]`；长度 `9500 B` 的最后一个字节偏移为 `9499`。
- 默认磁盘请求中，SCAN 与 LOOK 的服务顺序相同；前者多走 `183→199→183`，因此多移动 32 个磁道。

这些是固定条件下的机制检查。新增 I/O 阻塞、切换耗时、多级页表或预取时，应重新列条件，不能直接套演示的数值。
