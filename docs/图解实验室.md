# 图解实验室

有些概念适合看定义，有些概念要看**状态怎样改变**。这里按问题组织站内的交互图解：先预测一步，再操作，再回到原文核对机制。示例都是教学用的小规模模型，不能替代真实程序测量或独立解题。

## 硬件：从位到程序执行

<div class="lab-catalog" markdown="1">

- <span class="lab-tag">01 / 数据表示</span>

    **有进位，就一定溢出吗？**

## 算法：从边界到搜索顺序

<div class="lab-catalog" markdown="1">

- <span class="lab-tag">07 / 二分</span>

    **为什么要排除 mid？**

    同时看候选区间、中点和返回值；试试一个不存在的目标。

    [打开二分查找 →](洛谷题目/1_1/二分查找.md#binary-demo)

- <span class="lab-tag">08 / 搜索</span>

    **同一棵树，队列与递归怎样改变顺序？**

    对照 BFS 出队顺序、DFS 首次进入顺序，以及返回时的调用链。

    [打开 BFS / DFS →](洛谷题目/8_1/bfs.md#search-demo)

- <span class="lab-tag">09 / 最短路</span>

    **第一次发现，等于最短路已确定吗？**

    看一个暂定距离从 5 被改进为 3，理解“松弛”与“确定”的差别。

    [打开 Dijkstra →](洛谷题目/10_1/dijkstra算法.md#dijkstra-demo)


- <span class="lab-tag">10 / 快速排序</span>

    **一轮分区结束，整个数组就有序了吗？**

    观察快排的扫描、交换与指针交错；用全部相等的输入检查过程能否推进。

    [打开快排分区 →](洛谷题目/3_1/快速排序.md#partition-lab)

- <span class="lab-tag">11 / 前缀和</span>

    **为什么要减去 L−1，而不是 L？**

    改变查询区间，看到被抵消的前半段；再试含负数的数组。

    [打开区间求和 →](洛谷题目/4_3/前缀和数组与记忆化.md#prefix-lab)

- <span class="lab-tag">12 / 回溯与剪枝</span>

    **找到一个解之后，为什么还要撤销选择？**

    在四皇后棋盘上逐步尝试、拒绝与返回，也可跳到下一个完整解。

    [打开四皇后回溯 →](洛谷题目/5_2/回溯.md#queens-lab)
