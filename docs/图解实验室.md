# 图解实验室

有些概念适合看定义，有些概念要看**状态怎样改变**。这里按问题组织站内的交互图解：先预测一步，再操作，再回到原文核对机制。示例都是教学用的小规模模型，不能替代真实程序测量或独立解题。

<div class="learning-route" markdown="1">

<span class="learning-route__label">一条阅读路线</span>

**先问现象 → 观察变化 → 解释原因 → 换一个输入验证**

看到动画或读懂结果，只能算建立了直觉；能不看演示独立推导下一步，才更接近真正理解。

</div>
