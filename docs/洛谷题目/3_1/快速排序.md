# P1177 【模板】排序

## 题目描述

将读入的 $N$ 个数从小到大排序后输出。

## 输入格式

第一行为一个正整数 $N$。

第二行包含 $N$ 个空格隔开的正整数 $a_i$，为你需要进行排序的数。

## 输出格式

将给定的 $N$ 个数从小到大输出，数之间空格隔开。

## 输入输出样例 #1

### 输入 #1

```
5
4 2 4 5 1
```

### 输出 #1

```
1 2 4 4 5
```

## 说明/提示

对于 $20\%$ 的数据，有 $1 \leq N \leq 10^3$；

对于 $100\%$ 的数据，有 $1 \leq N \leq 10^5$，$1 \le a_i \le 10^9$。

## 🧠 解题思路

1️⃣ 核心建模

输入一个数组 `a[i]`，要求：

```text
按升序排列
```

2️⃣ 性质分析

👉 排序问题的常见解法：

* 快速排序（本页采用的练习实现；题面只要求升序输出）
* 归并排序
* STL `sort`（标准规定排序效果与复杂度要求，不限定唯一实现）

👉 这里重点：**手写快速排序**

3️⃣ 算法选择（快速排序）

核心思想：

```text
选一个基准（pivot）
把数组分成：
左边 ≤ pivot
右边 ≥ pivot
递归处理两边
```

4️⃣ 快排核心步骤（必须掌握）

假设区间 `[l, r]`

 ✔ 1. 选基准

```cpp
int pivot = a[(l + r) >> 1];
```

✔ 2. 双指针分区

```cpp
int i = l, j = r;

while (i <= j) {
    while (a[i] < pivot) i++;
    while (a[j] > pivot) j--;
    if (i <= j) {
        swap(a[i], a[j]);
        i++, j--;
    }
}
```

✔ 3. 递归

```cpp
if (l < j) quick_sort(l, j);
if (i < r) quick_sort(i, r);
```


5️⃣ 关键细节（非常重要）

* 取中点处的值作为 pivot，不保证每次都能均匀分区，也不能消除最坏情况
* 本页采用 `i <= j`，交换后两端都推进；扫描方式、循环条件和递归边界要作为一套理解
* 递归边界不能写错
* 数据量到 `1e5` 时仍需关注分区偏斜、递归深度与具体测试数据，不能只凭数量保证耗时

6️⃣ 时间复杂度

* 平均：`O(n log n)` ✅
* 最坏：`O(n^2)`；固定选择中点处的值仍可能遇到不利输入

## 图解：先完成一轮分区 { #partition-lab }

沿用本页样例 `[4, 2, 4, 5, 1]`，下标从 `0` 开始。先把中点处的**值**复制为 `pivot = 4`，再用 `i`、`j` 从两端扫描。pivot 在本轮中保持不变，不是在每次交换后重新读取中间元素。

<div class="study-viz concept-lab" data-concept-viz="partition">
<p>静态过程：先交换下标 0、4，数组变为 [1,2,4,5,4]；i 扫到下标 2，j 也扫到下标 2；交换这个位置后仍要推进两端，最终 i=3、j=1。接着递归 [0,1] 与 [3,4]；右侧 [5,4] 仍未排好序。</p>
</div>

!!! question "全相等时，谁保证循环继续前进？"
    切换到“全部相等”：两段严格比较都不会移动指针，真正保证推进的是交换后的 `i++`、`j--`。一轮分区只是为子问题建立范围，不等于整个数组已经有序，也不保证某一个 pivot 元素恰好停在最终排名位置。

可以接着看 [第 k 小的数](../3_2/求第k小的数.md)：快速选择利用分区后的位置关系，通常只继续处理包含目标排名的一边；[标准库排序与选择](../../c++基础/algorithm常用函数.md#algorithm-contracts) 则要区分各自保证的结果。

## 💻 C++代码（手写快排）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 5;
int a[N];
int n;

void quick_sort(int l, int r) {
    if (l >= r) return;

    int i = l, j = r;
    int pivot = a[(l + r) >> 1]; // 选中间值

    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) {
            swap(a[i], a[j]);
            i++, j--;
        }
    }

    if (l < j) quick_sort(l, j);
    if (i < r) quick_sort(i, r);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    quick_sort(0, n - 1);

    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }

    return 0;
}
```

## ⚠️ 易错点

❌ 1. 交换后忘记推进

```cpp
if (i <= j) swap(a[i], a[j]); // 只交换却不移动，重复值可能让过程停住
```

✅ 本页完整的推进步骤：

```cpp
if (i <= j) {
    swap(a[i], a[j]);
    i++;
    j--;
}
```


❌ 2. 递归区间写错

```cpp
quick_sort(l, i); ❌
quick_sort(j, r); ❌
```

✅ 正确：

```cpp
quick_sort(l, j);
quick_sort(i, r);
```


❌ 3. 把选择中点当作最坏情况保证

```cpp
int pivot = a[(l + r) >> 1]; // 这是基准值的选法，不是最坏复杂度保证
```

选区间首元素也能组成正确的快排，但某些输入会导致分区严重偏斜。不同分区版本可能使用不同的循环条件，不能脱离扫描、推进和递归边界，只记“某个符号一定对或错”。


❌ 4. 忘记边界判断

```cpp
if (l >= r) return;
```
