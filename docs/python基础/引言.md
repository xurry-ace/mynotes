# Python基础

## 用一条程序主线串起各章 { #python-map }

Python 的语法很多，可以先把它们放回一段程序里：**读入数据 → 组织数据 → 控制步骤 → 封装逻辑 → 保存结果**。面向对象和 NumPy 分别帮助组织更复杂的对象，以及处理数组运算。

[4 · 函数与模块](第4章：函数与模块.md) → [5 · 对象与类](第5章：面向对象基础.md) → [6 · 文件与路径](第6章：文件与文件夹操作.md) → [7 · NumPy 数组](第7章：重点突破--Numpy库.ipynb)

</div>
