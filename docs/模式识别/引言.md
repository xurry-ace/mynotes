# 模式识别

## 把“流程”和“方法”分开看 { #pattern-map }

学习路线可以按三件事组织：**数据怎样表示、模型怎样区分、结果怎样评价**。PCA、Fisher、SVM 不处在完全相同的位置，也不应该只按名字背一串公式。

<div class="concept-flow" markdown="1">

<div class="flow-step" markdown="1">

**01 / 表示数据**

特征、标准化、降维；先明确每个样本怎样表示。

[PCA：保留较大方差方向](考试复习.md#pca)

</div>

<div class="flow-step" markdown="1">

**02 / 学习区分**

利用标签或分布假设，建立判别或分类规则。

[Fisher：投影后的类间区分](考试复习.md#fisher) · [SVM](考试复习.md#svm)

</div>

<div class="flow-step" markdown="1">

**03 / 评价与选择**

用独立数据检查泛化；指标需要与任务目标匹配。

[阈值、混淆矩阵与 ROC](考试复习.md#metrics-lab)

</div>

</div>

!!! note "方法可以组合，角色要分清"
    PCA 是不利用类别标签的线性降维方法；Fisher 线性判别利用类别标签寻找区分方向。降维可以作为分类前的一步，而不是与所有分类器互斥。[查看考试范围与题型](考试题型.md) 或 [进入复习题](考试复习.md)。
